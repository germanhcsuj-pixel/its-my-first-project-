## 🛠 Технологии
* **Фронтенд:** Next.js (App Router), React 19, TailwindCSS
* **Рендеринг видео:** Canvas 2D API + WebGL (для сложных эффектов)
* **Архитектура:** Имеется древовидная структура нод (`RootNode`, `VideoNode`, `TextNode`, `TransitionNode`), которые собираются в `scene-builder.ts`.

## ✅ Что было сделано в предыдущем чате:
1. **Переходы (Transitions) для одиночных клипов:** 
   * Мы переписали `scene-builder.ts`, чтобы переходы можно было применять к клипам без соседей (например, плавное затухание в конце). Для этого создаются невидимые "пустышки" (`dummyNextElement` / `ColorNode("transparent")`), в которые уходит переход.
   * UI в `transitions.tsx` был обновлен, чтобы позволять применять переход к одному клипу (`updateElement`).
2. **Оптимизация производительности рендера (scene-builder.ts):**
   * Избавились от дублирования создания одних и тех же нод. Теперь ноды создаются один раз, кэшируются в `nodeMap` и переиспользуются для переходов.
   * Предрасчет `hideRanges` для скрытия оригинальных клипов во время рендеринга переходов.
3. **Исправление багов с z-index слоев:**
   * Была проблема, когда `TextNode` (текст) прятался за видео-оверлеями из-за неправильной сортировки массивов в `scene-builder.ts`. 
   * **Решение:** Возвращена строгая сортировка по `index` сверху вниз (`overlayTracks.sort((a, b) => b.index - a.index)`), что гарантирует правильный z-index при рендере в Canvas.
